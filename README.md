# Kotoba Mate｜日文單字複習助手

Kotoba Mate 是一個為 JLPT 備考設計的互動式日文單字複習工具。使用者可以將寫題過程中遇到的不熟悉單字加入個人單字庫，透過隨機出題、日文語音及熟悉度評分，反覆練習並追蹤自己的學習進度。

## ✨ 主要功能

- **單頁式分頁切換**：提供「單字卡複習」與「弱點排行榜 TOP 10」雙分頁，輕鬆切換卡片測試與錯題統計。
- **弱點排行榜 TOP 10**：自動統計歷史紀錄中按過「✕ 忘了」次數最多的單字並進行排名，協助快速找出並攻克最常忘記的魔王單字。
- **彈性多重組合篩選**：
  - **出題模式選單**：支援「隨機混合」、「只抽漢字」、「只抽平假名」。
  - **熟悉度選單**：支援「全部熟悉度」、「熟悉度 0」、「熟悉度 1～4 以下」分層過濾。
  - **近期新增開關**：可自由搭配上述兩大選單使用，精準鎖定近 2 天（當天與前一天）新增的單字庫。
- **智慧語音播放**：抽到平假名時自動朗讀發音；抽到漢字時預設不播音，需點擊「🔊 重播發音」手動播放，避免提前暴雷讀音。
- **複習歷史紀錄**：查看答案時同步顯示該單字的歷史評分紀錄（如 `✕ 忘了`、`△ 有點印象`、`◯ 記起來了`）與累計複習次數，精準掌握單字熟練度。
- **加權隨機出題**：依照單字熟悉度與天數紀錄調整出題機率，優先抽考不熟悉及近期新增的單字。
- **單字庫管理與備份**：支援單字手動新增，以及 CSV 批次匯入與匯出。
- **學習統計與考試倒數**：即時顯示單字總數、平均熟悉度，並自動計算距離 JLPT 考試日期的剩餘天數。
- **本機資料保存**：所有進度皆透過 `localStorage` 儲存於本機瀏覽器，無須註冊帳號即可使用。

## 🚀 使用方式

1. 開啟 `index.html`，或前往 GitHub Pages 部署的網站。
2. 新增單字，或使用 CSV 檔案批次匯入單字庫。
3. 透過上方下拉選單與按鈕，自由搭配出題模式、熟悉度門檻與「近期新增」條件。
4. 先試著回想單字的讀音、漢字或中文意思。
5. 點擊「查看答案」確認讀音與意涵，並同步查看過去的複習紀錄與發音。
6. 根據回想狀況進行熟悉度評分，系統將紀錄歷程並自動抽取下一題。
7. 切換至「📊 弱點排行榜 TOP 10」分頁，掌握自己最常忘記的單字。
8. 定期點擊「匯出 CSV」備份個人單字庫。

## 📁 範例檔案 (example.csv)

專案根目錄中附帶了一個 `example.csv` 檔案，可用於快速體驗或作為匯入格式參考。

### CSV 欄位說明
- **漢字**：單字的漢字寫法（若無漢字可留空）。
- **ひらがな**（或 `平假名`）：單字的平假名讀音（必填）。
- **意味**（或 `中文意思`）：中文解釋（必填）。
- **熟悉度**：預設為 0～5 的整數（匯入時若未填，預設為 0）。
- **day**：距離考試剩餘天數（系統依此欄位判定「近期新增」的單字）。

> 💡 **匯入注意事項**：匯入時系統會依據「漢字 + 平假名」自動過濾重複單字，已存在的單字不會被覆蓋。

## 💾 資料保存與備份

單字資料與學習歷程會保存在瀏覽器的 `localStorage` 中。資料不會自動同步至其他裝置，換瀏覽器或清理瀏覽紀錄前，請務必定期匯出 CSV 備份。
