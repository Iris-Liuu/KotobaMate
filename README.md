# Kotoba Mate｜日文單字複習助手

Kotoba Mate 是一個為 JLPT 備考設計的互動式日文單字複習工具。使用者可以將寫題過程中遇到的不熟悉單字加入個人單字庫，透過隨機出題、日文語音及熟悉度評分，反覆練習並追蹤自己的學習進度。

## ✨ 主要功能

- **三種出題模式**：隨機混合、只抽漢字、只抽平假名。
- **加權隨機出題**：依照單字熟悉度與新增時間調整出題機率，優先複習不熟悉及近期新增的單字。
- **日文語音播放**：使用瀏覽器內建的語音合成功能聆聽單字發音。
- **熟悉度追蹤**：透過「忘了」、「有點印象」及「記起來了」三種選項更新熟悉度。
- **個人單字庫**：支援新增單字、CSV 匯入與匯出。
- **學習統計**：顯示單字總數與平均熟悉度。
- **JLPT 考試倒數**：自動計算距離考試日期的剩餘天數。
- **本機資料保存**：使用 `localStorage` 保存單字資料與學習進度。

## 🚀 使用方式

1. 開啟 `index.html`，或前往 GitHub Pages 部署的網站。
2. 新增單字，或匯入既有的 CSV 單字檔。
3. 選擇喜歡的出題模式。
4. 嘗試回想單字的讀音、漢字或中文意思。
5. 點擊「查看答案」，確認答案並聆聽發音。
6. 根據實際熟悉程度評分，系統將更新熟悉度並抽取下一題。
7. 定期匯出 CSV，備份個人單字庫。

## 💾 資料保存與備份

單字資料與熟悉度會保存在瀏覽器的 `localStorage` 中。資料不會自動同步至其他裝置或瀏覽器，建議定期匯出 CSV 備份。
